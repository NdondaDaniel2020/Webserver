O que é o Webserv?

O Webserv é um servidor HTTP escrito inteiramente em C++98, seguindo as normas do protocolo HTTP/1.1. Desenvolvido como projeto da 42, ele replica funcionalidades reais de servidores como o NGINX — mas construído do zero.

Utiliza poll() para multiplexação de I/O, garantindo que nenhuma conexão bloqueia o servidor. Suporte completo a métodos HTTP, configuração via ficheiro, e execução de scripts CGI.

  • Non-blocking I/O com poll()
  • Suporte a GET, POST e DELETE
  • Sistema CGI (PHP / Python)
  • Múltiplos ports e virtual hosts
  • Ficheiro de configuração customizável
  • Páginas de erro personalizadas
